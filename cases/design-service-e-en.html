Service E

I didn’t port the interface, I took it apart and rebuilt it. A document processing system for the Central Bank: signing and encryption pipelines, role-based access, monitoring. The interface already existed but wasn’t intuitive, so I led the team through full discovery.

Approach

A document processing system for the Central Bank with an unintuitive interface. Instead of moving it over as-is, I led the team through discovery: personas, JTBD, a story map, an object model.

Design pipeline

We built the discovery artifacts together with the team. So the work wouldn’t depend on a single designer, I built a pipeline: an AI agent walks the task through the stages, asks questions in plain language and draws each artifact on a FigJam board in a consistent style. A person reviews the artifact’s text first, and only then does it go on the board. The pipeline made producing artifacts easier for the bank’s teams: no design experience is needed.
